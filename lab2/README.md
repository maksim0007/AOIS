# Лабораторная работа 2

Проект решает ЛР по построению СДНФ/СКНФ на основании таблицы истинности.

## Что реализовано

1. Ввод логической функции с операциями `&`, `|`, `!`, `->`, `~` и переменными `a,b,c,d,e`.
2. Таблица истинности.
3. СДНФ и СКНФ.
4. Числовые формы СДНФ и СКНФ.
5. Индексная форма функции.
6. Классы Поста.
7. Полином Жегалкина.
8. Фиктивные переменные.
9. Частные и смешанные булевы производные от 1 до 4 переменных.
10. Минимизация расчетным методом для ДНФ и КНФ.
11. Минимизация расчетно-табличным методом для ДНФ и КНФ.
12. Табличный метод: карта Карно таблицей для ДНФ и КНФ.

Основная логика написана самостоятельно. `eval` не используется.

## Запуск

```bash
python cli_menu.py
```

или сразу полный отчет:

```bash
python -m logic_lab "!(!a->!b)|c"
```
