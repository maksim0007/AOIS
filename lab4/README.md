# Лабораторная работа №6
## Тема: моделирование хеш-таблиц
**Вариант 6: Литература**

Проект реализован на **Python 3.11+** без сторонних библиотек. Он подходит для открытия и запуска в **PyCharm**.

## Что реализовано
- вычисление числового значения ключевого слова `V(K)` по первым двум русским буквам;
- вычисление хеш-адреса `h(V) = V mod H + B`;
- формирование хеш-таблицы размером **20 строк**;
- обработка коллизий методом **внутренней адресации** с **линейным пробингом**;
- хранение полей строки таблицы: `ID, C, U, T, L, D, Po, Pi`;
- поиск записи по ключевому слову;
- вставка новой записи;
- удаление записи;
- защита от повторной вставки уже существующего ключа;
- расчет коэффициента заполнения таблицы;
- вывод всей таблицы и списка вычисленных `V(K)` и `h(V)`;
- unit-тесты с покрытием **выше 90%**.

## Как считается ключ
Используется русский алфавит:
`А=0, Б=1, ..., Я=32`

Для первых двух букв ключевого слова:
`V = index(буква1) * 33 + index(буква2)`

Далее:
`h(V) = V mod H + B`

Для проекта:
- `H = 20`
- `B = 0`

Пример:
- `Поэма` -> `П`, `О`
- `V = 16 * 33 + 15 = 543`
- `h = 543 mod 20 = 3`

## Краткие ответы для защиты
1. **Для чего используются таблицы хеширования?**  
   Для быстрого поиска, вставки и удаления данных по ключу.

2. **Что используется для программного поиска информации по содержанию?**  
   Ключевое слово, которое преобразуется в числовое значение и хеш-адрес.

3. **Назовите основные функции хеширования.**  
   Вычисление `V(K)` и преобразование `V` в адрес `h(V)`.

4. **Приведите структуру хеш-таблицы.**  
   Строка включает `ID, C, U, T, L, D, Po, Pi`.

5. **Приведите способы перевода ключевых слов в числовые значения.**  
   По первым буквам, по кодам символов, по позиционному представлению, по сумме кодов символов.

6. **Приведите способы преобразования числового значения ключевого слова в хеш-адрес.**  
   Через остаток от деления, метод середины квадрата, мультипликативный метод и другие.

7. **Что такое коллизия? В каких случаях она возникает?**  
   Коллизия возникает, когда разные ключи получают один и тот же хеш-адрес.

8. **Назовите способы обработки коллизий.**  
   Внутренняя адресация, пробинг, цепочки, область переполнения.

9. **В каких случаях производится процедура пробинга?**  
   Когда вычисленная ячейка занята и нужно найти резервное место для записи.
